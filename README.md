# ShopKart – E-Commerce Website

ShopKart is a modern e-commerce frontend inspired by popular online shopping platforms. It provides a clean, responsive shopping experience with a user-friendly interface and essential e-commerce functionality.

## 🚀 Tech Stack

- **Frontend:** Next.js, React.js, TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Storage:** Browser Local Storage

## ✨ Features

- Modern and responsive user interface
- Product listing and browsing
- Product search and filtering
- Shopping cart functionality
- Cart data persistence using Local Storage
- Interactive shopping experience
- Responsive design for desktop, tablet, and mobile devices

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/sanket2407kadam/ShopKart.git
```

### 2. Navigate to Project

```bash
cd ShopKart
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```

## 🏗️ Build for Production

```bash
npm run build
```

To start the production server:

```bash
npm start
```
